#### 🏥 City Care Hospital – Patient & Billing Management System

A full-stack web application built using **Python, Flask, SQLite, HTML5, CSS3, and JavaScript** to streamline hospital patient admissions, live billing updates, and discharge invoice generation. 

#### ✨ Key Features

* **Patient Admission & Discharge:** Automated recording of entry/exit timestamps and stay duration calculation.
* **Live Billing & Ledger:** Add medicine/lab charges, apply hospital discounts, and track advance or partial payments in real time.
* **Live Dashboard Analytics:** Displays total patients, currently admitted count, discharged count, total revenue collected, and pending balance dues.
* **Tax Invoice & Receipt Generator:** Printable hospital receipt with automatic PAID IN FULL / BALANCE DUE stamps and dynamic accountant signature support.
* **Instant Search:** Search patient records by name, phone number, or assigned doctor.

#### 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Database:** SQLite3
* **Frontend:** HTML5, CSS3, JavaScript
